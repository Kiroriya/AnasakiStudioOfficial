# Money (example JS library plugin)

- `import { baht, round2 } from 'money'` — library functions, bundled into your code.
- `import { rate } from 'money'` — runs inside the money plugin (reads its own setting `usdRate`,
  set in Site code → Settings → unit "money").

Zip the folder (manifest.json at the root) and upload it in Plugins.
