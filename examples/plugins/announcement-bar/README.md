# Announcement Bar

แถบประกาศแสดงด้านบนทุกหน้าของเว็บไซต์ — ใส่ข้อความ ลิงก์ และเลือกสีได้ ผู้ชมกดปิดได้ (จำไว้จนกว่าข้อความจะเปลี่ยน)

A top-of-page announcement with a message, an optional link and custom colors. Visitors can dismiss it; it comes back when the message changes.

ถ้าปิดตัวเลือก "ให้ผู้ชมปิดได้" แถบจะแสดงเสมอ แม้ผู้ชมเคยกดปิดไว้ก่อนหน้า / With "Visitors can dismiss" turned off the bar always shows, even for visitors who dismissed it earlier.
