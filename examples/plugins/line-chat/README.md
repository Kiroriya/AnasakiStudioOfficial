# LINE Chat Button

ปุ่มลอยมุมจอสำหรับให้ลูกค้าติดต่อผ่าน **LINE**, **Messenger** หรือ **โทรศัพท์** — ช่องทางที่ไม่ได้กรอกจะถูกซ่อนอัตโนมัติ

A floating contact button for LINE, Messenger and phone. Empty channels are hidden automatically.

ตั้งค่า: LINE ID, ชื่อเพจ Facebook, เบอร์โทร, ข้อความบนปุ่ม, ตำแหน่ง (ซ้าย/ขวา) และสีปุ่ม

ใช้คีย์บอร์ดได้: กด Tab ไปที่ปุ่ม (มีกรอบโฟกัส) แล้วกด Space เพื่อเปิด/ปิดเมนู ลิงก์ในเมนูที่ปิดอยู่จะไม่ถูกโฟกัส /
Keyboard friendly: Tab to the button (focus ring shown), Space opens/closes the menu; links of a closed menu are skipped.
