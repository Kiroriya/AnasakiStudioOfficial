# Chat buttons (`chat-buttons`) — ปุ่มแชทและช่องทางติดต่อ

ปลั๊กอินทางการ: ปุ่มลอยมุมจอทุกหน้า กดแล้วเห็นช่องทาง LINE OA, Messenger, WhatsApp, Instagram, โทร และอีเมล
(ใช้ได้โดยไม่ต้องมี JavaScript), ซ่อนในบางหน้าได้ (เช่น `/checkout`) และบล็อก **ปุ่มติดต่อ (แชท)** สำหรับวางในหน้าติดต่อเรา

## English

A floating contact button on every public page (a `<details>` menu, no JavaScript) with LINE, Messenger, WhatsApp,
Instagram, phone and email links built from the settings, hidden on chosen paths, plus the designer block
`chat-buttons/buttons`. No tables, no scopes.
